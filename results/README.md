# Archived paper results

These files contain the numerical results used by the current manuscript. They support plotting and statistical reproduction without model training or API requests. They are historical measurements, not outputs regenerated by the revised method implementation.

- `benchmark/summary.json` provides the selected nine-task cohort, actual seeds, source run numbers, metrics and descriptive ranks for the current manuscript cohort.
- Each `benchmark/<dataset>/convergence.json` contains ten paired runs for all ten historical strategies, including per-round acquisitions and numerical diagnostics. `initial_sets.json` records the paired starting candidates.
- `ablations.json` contains 450 run summaries and their 7,150 per-round curve records for five module configurations, together with the reported task statistics and comparisons. The archive retains the recorded reuse of main full/static runs and the offline control with both FSR and EWRC disabled.
- `manifest.json` records the original and published file hashes, manuscript identity and transformations made for publication.

The historical strategy names `Hybrid` and `Hybrid-static` mean CALM and CALM-static. Main-paper comparisons use CALM and eight baselines; CALM-static remains available for supplementary analyses. The selected cohort is descriptive and includes the documented post-hoc run replacements. Superseded sensitivity/status snapshots and unused legacy inferential summaries are omitted from this publication view; they remain unchanged in the original research archive.

Candidate indices are zero-based positions after filtering the registered CSV to rows with a numeric target value, preserving CSV order. The data file hash in each task's summary binds that interpretation. The final Cu result includes all ten runs; the earlier nine-run Cu snapshot is not used.

Publication changes include JSON formatting, English selection descriptions, portable metadata paths and omission of historical summaries outside the current figure/table scope. Retained numeric observations, strategy/run order, candidate indices and metric values are unchanged. Paths beginning with `research_archive/`, and other original-source paths recorded in the manifest, identify provenance in the author archive; they are not files that the plotting scripts need to open. Caches, complete LLM evidence, model binaries, checkpoints and temporary files are not distributed here.
