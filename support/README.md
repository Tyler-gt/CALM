# CALM supplementary materials

English supplementary materials aligned with the final manuscript, revised on 16 November 2026. The manuscript text and scientific result values are unchanged.

| File | Contents |
|---|---|
| [Supplementary Information PDF](CALM_Supplementary_Information_English.pdf) | 40 pages: Sections S1–S13 and S15–S17, 22 figures and 21 numbered tables. |
| [Editable Supplementary Information](CALM_Supplementary_Information_English.docx) | The same document in Word format. |
| [Detailed Methods Word](S14_Methods_en.docx) and [PDF](S14_Methods_en.pdf) | Separate 11-page S14 draft, retaining 15 numbered equations, the complete algorithm and two tables. |
| [Supplementary Data S1 ZIP](Supplementary_Data_S1.zip) and [browsable files](Supplementary_Data_S1/) | Nine static-score datasets covering 3,849 candidates, with original precision and provenance manifests. |
| [Complete support package](CALM_English_Support_Package.zip) | Documents, data and the accompanying repository index and notes. |

The revision distinguishes the ten-strategy benchmark from the five-configuration module ablation, repairs cross-references, adds the two missing table numbers and removes redundant panels from Figures S16 and S17. Existing figure identifiers and manuscript references are retained.

The [data index](DATA_INDEX.md) links to results available in this repository and identifies research archives that are not distributed here. [CURRENT_SUPPORT.json](CURRENT_SUPPORT.json) records file hashes. Original research paths inside data manifests are provenance identifiers, not links into this repository.

S14 remains a separate Methods draft. The [journal-format note](JOURNAL_FORMAT_NOTES.md) records the outstanding integration into the main Methods for npj Computational Materials. The main manuscript has not been changed as part of this update.

The PDF, Word and score files are identical to the reviewed English release. The GitHub package adapts only the landing page, data index and package inventory to this repository. Data attribution remains as described in the repository's DATA_SOURCES.md and the score manifest.
